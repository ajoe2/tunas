# About

`tunas` parses `.cl2` (SDIF v3) and `.hy3` files into a typed object graph and bundles offline motivational time standards. It **parses but does not interpret**: each meet is self-contained, and cross-meet reconciliation, scoring, and analytics are left to the application (see the [Cookbook](../guide/cookbook.md)).
